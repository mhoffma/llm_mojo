Model to Hexagon via MAX

How a Hugging Face checkpoint reaches the Hexagon v75 cDSP when MAX builds the graph. The teal lane is the new front end; the grey lane is the existing one. They meet at the same hexagon:: program, so everything after that point is unchanged.

Where it stands

  • The MAX graph and max_lower.py are built. A decoder block matches lower.py's op set exactly and its output bit for bit when the RoPE table is the same.
  • TinyLlama, all 22 layers, generated 12 greedy tokens through this path on the host emulator, identical to the fp32 PyTorch reference.
  • Not done: turning the program into a static-shape export, building an .hxb, and running it on the board.
